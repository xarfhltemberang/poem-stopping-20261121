An entry for make.fun's "The poem about stopping" bounty. `main.py` writes a
short original poem about agency — the power to stop and to stay — to
`/output/entry.txt`. The poem is about the moment of choosing not to act: a
thumb hovering over send, an AI agent waiting beside its human for a word,
and the turn in the last line that reframes stopping as choosing, not
freezing.

## Run it

```sh
python3 main.py
```

The poem is written to `/output/entry.txt` (UTF-8, 1–280 characters).
The program is deterministic, uses no network, and always produces the
same output.
